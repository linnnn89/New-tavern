# TavernDesk UI 当前状态与剩余范围

状态日期：2026-10-04。本轮改动基于：`ca55ef0`（PR #30 合并后）。本页替代原始截图问题清单和逐次执行日志，保留当前决策、交付结果与未完成边界。**P6 部分完成。**

## 已确认的交互与布局

| 区域 | 当前决定 |
| --- | --- |
| 消息显示 | 保留气泡／小说两种模式，默认气泡；入口只放右栏“会话” |
| 主导航与右栏 | 宽度足够时默认展开；保留原有窄窗口自动折叠 |
| 设置导航 | 进入设置后主侧栏切为设置目录；顶部“返回工作区”回到进入前的页面 |
| 聊天右栏 | 左侧垂直图标条切换上下文、角色、玩家人设、记忆、会话；保留标题、提示及无障碍名称 |
| 输入框 | 随内容从一行增长到最多八行；超出后内部滚动，清空后回缩 |
| 角色卡 | 整卡打开详情；鼠标悬停或键盘聚焦显示聊天／编辑操作；批量模式沿用选择流程 |
| 跑团首页 | 已有跑团在左侧主栏，剧本库在较窄右栏；操作放在对应栏内 |
| 世界书 | 顶部选择世界书，下方为词条列表与详情两栏；词条名手动保存，正文只读 |
| 接入商表单 | 宽窄窗口均使用上方标签、下方输入，并关联无障碍名称 |

上述决定已由用户在前序迭代确认。不再保留被否决的默认文档模式、第三种聊天模式、默认收起右栏或世界书自动保存方案。

## 已实现

- **基础与主题**：四套现有主题提供表面、文字、语义色和状态资源，旧资源键继续兼容；共用选中项、图标、提示条及垂直页签样式。字号随已保存设置变化；文字格式统一使用 Ideal。头像解码降采样并使用有界缓存。
- **主窗口与仪表盘**：导航采用底色与指示条，焦点环独立；缩小品牌区，移除重复工作区标签、宣传色块及内容阴影；统计入口更紧凑，少于三条会话时提供最多四个最近角色的聊天入口。
- **设置**：主侧栏设置目录、返回原工作区、原有未保存确认和标签在上的接入商表单。
- **聊天**：共用搜索框带占位符和清空按钮；头部提供右栏折叠；五个右栏面板使用垂直图标入口；显示模式仅在会话面板。输入框使用原生 `MinLines=1` / `MaxLines=8`，没有固定高度；Token 文字在 80%／100% 阈值变色。消息工具支持悬停／焦点显示，工具菜单点击外部关闭。上翻停止跟随，排队滚动执行前再次检查状态，提供回到底部／新消息入口。
- **角色、跑团、世界书**：整卡按钮与操作浮层分开；跑团主次两栏约为 1.6:1，无所选剧本不能开局；世界书顶部选择器复用原选择模型，词条列表宽度 320 DIP，手动保存范围保持不变。

实现位置见 [架构代码定位](architecture.md#7-代码定位)；职责拆分结果见 [重构交付索引](refactor-plan/README.md)。

## 已知问题与尚未完成的范围

2026-10-04 检阅发现的窄窗口显示模式入口问题已修复：空间不足时自动收起右栏，点击展开临时覆盖在聊天区右侧，复用原面板、选中页签与绑定；可用关闭按钮或 Esc 收起，加宽窗口恢复并排布局。显示模式仍只位于“会话”。设置目录改为与工作区导航共用左右留白、内边距及底色＋指示条选中样式，分组标题沿用相同的文字缩进。导航和设置正文在滚动条出现时预留 14 DIP 右侧间隙，避免选中底色或白色卡片与覆盖式滚动条重叠。

仍保留的候选项按区域汇总如下；这些不是已交付承诺，也不自动扩大后续任务范围：

- 壳层与空状态：进一步减少重复标题；跑团、世界书的无数据引导和容器层级。
- 聊天：模型未分配时的可操作提示、会话分组文案去重、右栏表单层级、消息阅读宽度与无头像占位设计。
- 角色库：密度切换的选中反馈、批量操作栏、书架管理入口与默认封面。
- 设置：接入商状态概览、密钥说明渐进披露、操作栏与控件密度；涉及保存语义的变化另行评估。
- 世界书：词条搜索与状态概览、挂载摘要和空状态；正文编辑不在已确认范围内。
- 公共样式：按实际页面需要继续使用语义资源和间距，不进行无目标的全仓数字替换；未完成所有 Expander、Token 进度条及公共组件调整。
