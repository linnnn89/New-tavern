## 2026-08-12 — 普通群聊共同记忆与角色独立记忆

### 目标与实现

- 普通群聊新增两级长期记忆：所有成员共用的共同记忆，以及按“群聊 + 角色”隔离的独立记忆。角色卡原有长期记忆继续单独保存；群聊自动更新不读取、不覆盖它。群聊内容只有通过既有“生成合并草稿 → 用户确认保存”流程才会写入角色固有长期记忆。
- 群聊上下文只注入共同记忆和当前发言角色的群聊独立记忆，不注入其他成员的独立记忆，也不自动注入角色固有长期记忆。群聊设置新增独立记忆开关；关闭后已有独立记忆也停止注入和自动更新。
- 自动更新改为按一次完整接力结束后调度，并按完整保存的消息数或待处理 Token 估算阈值触发；因此只有角色自动接力、没有新增 USER 消息时仍能更新。手动按钮可立即检查并更新。
- 新更新器要求模型返回 `body + sourceThroughMessageSequence` 结构化 JSON，并校验正文非空、长度和来源边界。共同记忆与各角色独立记忆先全部生成并验证，再用同一 SQLite 事务保存；任一范围失败时整批旧正文和检查点保持不变。
- 检查点保存已处理消息数量与来源 SHA-256。编辑、删除或切换已处理候选后，下一次检查会只依据当前群聊消息重建，不沿用已失效正文。
- SQLite schema 升至 v20，新增 `group_memory_banks`、`group_memory_checkpoints` 及群聊独立记忆开关/阈值；旧 `group:{conversationId}` 群聊记忆迁移为共同记忆。群聊分支继续不复制已生成记忆，但会继承新增设置。
- 群聊设置卡新增四语说明、独立记忆开关、待处理 Token 阈值、状态和“立即检查并更新”按钮。没有启动可见 GUI，本轮外观只通过 XAML 编译与资源契约验证。

## 2026-08-02 — 精炼提示词与缓存友好请求顺序

### 调查与设计判断

- AI GM 的手动裁定行为在执行层已经存在，但旧界面把“让当前 AI 席位行动”“提交/生成 GM 裁定”等不同职责并列成抽象按钮，缺少主持方式、当前阶段和前置条件说明，视觉上容易被理解为 USER 在管理 GM。
- 用户确认：AI GM 永不自动调用；协作圆桌逐席手动触发任意未行动 AI，严格先攻只开放当前席位，秘密同投保留同一冻结快照的一次批量并发；AI 失败只能重试或换模型，不允许跳过；未来顺序发言复用同一席位策略入口。

### 实现

## 2026-08-03 — 跑团自动行动骰与 GM 裁定协议

### 根因与规则冻结

- 现场记录显示手动 `1d20` 只是独立本地事件，现有 `ModelExecutionRequest` 又没有工具/函数调用字段，因此 AI GM 无法主动调用骰子；短 GM 默认提示词也没有说明何时、如何结合骰点裁决，GM 上下文缺少玩家席位所有权与冻结角色资料，模型容易退化为普通旁白或替玩家继续表演。
- 结合联网核对的常见跑团共识与用户确认，冻结 TavernDesk 自有规则：GM 控制世界、NPC、环境与后果，玩家控制自己的台词、心理、决定和下一步；GM 可以描述已提交行动如何展开并引入新剧情，但不能替玩家决定面对后果后的反应。
- 每条 USER/AI 玩家行动都自动附带显性的统一 `1d20`。高低点只提供正负倾向，`1`/`20` 不是绝对失败/成功；不可能之事不会因 20 自动实现，已说出的台词或安全行动也不会被 1 抹除。纯对话或低风险行动可让点数影响 NPC 反应、机会、细节或局势变化。
- 每次 GM 发言以 `【下一轮评定参考】` 说明下一轮的情境风险、机会与可能影响裁定的因素，但不能规定必选路线、指定技能、台词或反应。AI GM 缺失该非空最终章节时视为未完成，不允许推进回合。

### 实现

- USER 行动在创建 `PlayerIntent` 前生成 `1d20`；AI 行动只在流式输出完整结束时生成。正文末尾的 `【随行动评定骰】1d20 → [N] = N` 与 `taverndesk.campaign-action-roll.v1` 结构化 JSON 在同一次事件插入或终态事务中写入，骰点继承行动可见性；失败、中断或截断的 AI 尝试不生成骰点。
- 保留原 `NdM±K` 工具作为“额外掷骰与记录”，界面明确它只创建独立公开骰点，不能替代玩家行动自动骰。USER 行动区同步提示提交时会自动附带 `1d20`。
- GM 请求在可编辑全局提示词之外强制追加运行时回合协议，并列出全部启用席位的类型、所有权和冻结角色/Persona 资料。AI 玩家请求强制说明不得自行掷骰、伪造或预判系统点数；即使用户保留自定义全局提示词，核心运行时边界也不会消失。
- 内置 GM/玩家默认提示词加入同一规则，并以一次性 `prompts.campaignActionRollV5.applied` 迁移精确替换上一版内置默认；任何自定义提示词保持原样。
- GM 开场和未自行填写收尾的 USER GM 裁定会附加灵活的通用 `【下一轮评定参考】`。AI GM 输出由执行器校验；缺失时终态为 `ProtocolViolation`、`IsLocked=false`，原文保留且不进入世界摘要。重试另建事件并通过 `AttemptNo`/`ReplacesEventId` 串联，只有有效收尾成功后才推进回合。
- 世界摘要会剥离 `【下一轮评定参考】`，避免把面向玩家的下一轮提示误当成已经发生的世界事实；不可变事件历史仍保留完整显示文本。
- 秘密同投的行动及其自动骰在当前回合只对提交者与 GM 可见；GM 裁定完成、轮号推进后，历史上下文与界面再一起揭示。
- 剧本导入模板同步改为自动行动骰和情境化解释；既有冻结剧本不依赖模板更新，因为运行时强制协议覆盖所有战役。
