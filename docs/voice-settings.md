# 角色语音设置与行为

本页记录 Fish Audio 的参数、保存、播放、缓存和错误处理细节。基本安装与功能见[项目首页](../README.zh-CN.md)。

### 手动角色语音（Fish Audio）

- 普通单聊和群聊的每条角色消息下方都有小喇叭。点击后才生成并播放；再次点击停止。收到回复、打开聊天或切换候选都不会自动生成语音。用户消息和系统消息不提供角色朗读按钮。
- 在“设置 → 语音”中填写 API 地址、Fish Audio API Key 和默认音色的 `reference_id`。点击消息旁的齿轮也可修改这些设置，并为当前角色指定专用音色。角色绑定使用角色 ID，重名角色不会混用音色。密钥通过 Windows DPAPI 加密保存，留空保存时保留原密钥，也可勾选清除密钥。
- 多个设置窗口保存时只合并各自实际修改的字段；只修改角色音色不会覆盖其他窗口新保存的模型或全局参数。若其他窗口已更改 API 地址或密钥，旧窗口修改地址、替换/清除密钥或恢复推荐值时会提示重载并核对，避免错误组合地址与密钥。失败时保留当前输入，重载会丢弃这些未保存的修改。
- 保存、重载和恢复推荐值按钮固定在底部。输入无效时会在字段旁显示原因，自动滚动并聚焦该字段，高级参数错误会展开高级设置；输入控件提供无障碍名称和关联标签。存储失败单独提示。新配置提交后即生效，旧密钥清理失败会单独提示并记录错误日志，不会把已成功的保存报告为失败。
- 关闭消息齿轮打开的语音设置时，如有未保存修改，会提示保存、放弃或取消，默认取消；关闭确认框也会保留当前输入。保存过程中暂时不能关闭窗口，校验失败或出现旧密钥清理警告时窗口保持打开。
- 默认模型为 `s2.1-pro-free`，适合免费账户测试；下拉包含 `s1`、`s2-pro`、`s2.1-pro`、`s2.1-pro-free`、`drama-3-preview` 和“自定义”。自定义模型 ID 原样发送。Fish 官方接口可能把未知 ID 回退到默认模型，因此免费账户应明确选择 `s2.1-pro-free`。语音模型与音色 `reference_id` 是两个不同参数，语音模型与聊天模型也独立配置。
- 默认 API 地址为 `https://api.fish.audio/v1/tts`，可改为 Fish 兼容的 HTTPS 地址；本机服务允许 HTTP。密钥会发送到指定地址，不跟随 HTTP 重定向。配置保存、重载及恢复推荐值均不会调用 TTS。
- 推荐值参考 [Fish TTS 文档](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)：语速 `1`、音量 `0 dB`、`temperature/top_p = 0.7`、`chunk_length = 300`、`min_chunk_length = 50`、`latency = normal`、`max_new_tokens = 1024`、`repetition_penalty = 1.2`、`early_stop_threshold = 1`。默认开启文本规范化、响度规范化和前段音频条件，默认关闭可选的 `quality-guard`。这些参数均可修改；“恢复推荐值”明确重置模型、API 地址及合成参数，保留密钥和音色，点击保存后生效。即使旧窗口原本显示推荐值，保存也会应用此次重置，不会保留其他窗口后来选择的付费模型。
- 当前播放器固定使用 PCM、44100 Hz、16 位单声道；不提供无法播放的 MP3/Opus 参数。每条角色消息单独合成，不上传参考音频，也不需要下载模型。
- 全应用一次播放一条语音；点击另一条会停止前一条。当前会话开始新回复、切换或删除会话，或编辑、删除、重新生成、切换正在朗读消息的候选时会停止播放。生成或加载期间喇叭禁用并显示等待提示；已在播放时仍可停止。
- 只朗读当前显示的正文副本，去除代码块、图片和成对的加粗/行内代码标记，保留普通星号、未闭合标记、尖括号和大小比较表达式，不修改聊天记录。完整播放成功的音频保存到系统“我的文档”下独立的 `TavernDesk-AudioCache` 目录，文件名使用摘要，不保存聊天正文或密钥。单条最多 32 MiB，总音频上限 120 MiB；不足时按写入时间从旧到新清理。本次运行内，正文、音色、模型、API 地址、合成参数及密钥配置相同可直接重播。中断或失败的音频不缓存，下次启动时清空旧缓存。语音设置页显示路径、占用量和文件数，可点击“刷新缓存占用”；缓存目录不可用时仍能直接生成播放。
- 语音设置页提供“测试连通性”：使用当前未保存的配置和固定短句请求音频，不播放、不保存设置、不发送聊天正文；可取消，最长 30 秒，可能消耗 API 额度。密钥框留空时复用当前已保存连接的密钥；地址或已保存连接发生变化时，须重新输入本次测试的密钥。
- 语音请求、响应格式、音频流及播放异常记录到 `%LOCALAPPDATA%\TavernDesk\logs\taverndesk-errors.jsonl`，不需要开启 API 测试模式。记录失败阶段、请求参数结构（正文与音色 ID 隐去）、HTTP 状态、脱敏后的 JSON 错误和异常类型/堆栈；不保存音频或聊天正文。服务端回显正文的字段及识别出的故事片段会隐藏；非 JSON 或超过 16 KiB 的错误正文不保存，读取错误正文最长 5 秒。主动取消不记为失败，不自动重试。
- 生成失败会在消息下方显示原因，不自动重试；再次点击可能产生新的 Fish API 用量。本功能目前接入普通对话页面，独立跑团页面未接入。
